# MiSans

本扩展使用 MiSans Regular（400）与 Semibold（600）字体，来自[小米 MiSans 官方](https://hyperos.mi.com/font/zh/)。

原始下载包：[MiSans.zip](https://hyperos.mi.com/font-download/MiSans.zip)。两个 WOFF2 文件均直接复制官方原文件，未修改或裁剪；适用许可随附于 MiSans-license.pdf。许可第 2 条禁止对字体或其组件改编、二次开发，因此不做子集化或格式转换；两个文件约占源码包的 9.5 MB，这是有意保留的。

字体只随本扩展使用，不独立销售或分发为字体产品。无需安装系统字体，扩展不会从远端请求字体。
