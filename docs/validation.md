## 访问暂停与失效记录（2026-11-23 至 2026-11-24）

- 隔离浏览器验证了 `300013` / HTTP `429` 触发的暂停。刷新只允许手动重试。再次遇到限制会重新暂停，轮询和重开面板不会自动继续读取。
- 确认失效的笔记在正文和图片任务中均会跳过。重启、跨收藏夹和链接参数变化后的跳过行为，以及备份恢复后保留既有内容，均有回归覆盖。
- 测试覆盖临时故障、登录验证、引用文字、隐藏提示和跨笔记重定向，避免它们误入永久失效列表。真实失效页的现场复现仍待验证。

- 真实站点上的扫描接管、真实浏览器中的快照清理效果以及部分命中线索的人工相关性仍待验证。

## 已知限制

- 真实收藏夹的全量覆盖、正文取得比例、长期稳定性和真实站点补图仍待验收。面板以各任务已确认的进度和缺口为准。
- 安装检查分别报告本地组件、浏览器连接和 Skill 状态。各用户环境的首次安装、浏览器连接及新聊天自动选用 Skill 需要分别核验。
- 真实图片 OCR 质量、跨 Agent 宿主接入和真实资料下的端到端效果仍需单独验证。
