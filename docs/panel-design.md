# Chrome 插件面板设计

## 2026-11-24：已采用的 iOS 风格界面

本节记录扩展弹窗当前采用的 iOS 风格界面。后续章节记录此前的设计与验证。

- 弹窗固定 **360 × 600px**，顶栏 68px，主内容左右内距 20px。`html` 与 `body` 的宽度和最小宽度均显式设为 360px，不使用 `100vw` 限制；`body` 显式继承字体，避免 Chrome 扩展页的默认字体覆盖。内容纵向滚动，并为浮动底栏预留底部空间。
- 内容使用实底，操作使用玻璃材质。进度卡与读取内容保持清晰背景，刷新按钮、底部工具栏和临时面板采用半透明、模糊及细边缘。内容卡圆角 22px，主按钮圆角 23px，工具栏圆角 26px；玻璃不覆盖正文可读性。
- 浅色采用背景 `#F5F5F7`、内容 `#FFFFFF`、文字 `#242529`、陶土红 `#A64733`；深色采用背景 `#19191C`、内容 `#26262B`、文字 `#F1F1F3`、强调色 `#EFB29D`。Apple 平台优先系统字体，Windows 回退到本地 MiSans；收藏标题 22px，正文与操作 11–14px，辅助信息 10–11px。数字使用等宽数字，百分号弱化字号。
- 收藏列表与正文保存保留同排 64px 圆环及完整计数。列表比例是“已发现 / 已知总数”，正文比例是“已保存 / 已发现”；未知总数、零分母及断连显示静态空环与“—”。接近完成时不会提前显示 100%，列表数量达到 100% 也不代替末尾确认；失效项跳过不会计为正文已保存。
- 常用操作保持两列按钮；普通读取中的暂停和暂停后的继续突出为主操作，核对末尾时突出确认操作。补全正文的主界面提示压缩为摘要，完整限制与失败原因保留在详情中。不可用操作仍禁用并提供原因，刷新与“重新检查”仍走原有业务逻辑，不自动恢复被限制的读取。
- 底栏的“读取详情 / 设置 / 帮助”打开单层 sheet。面板支持关闭、Escape、Tab 焦点约束与关闭后的焦点恢复；快速关闭再打开会取消旧退出动作。任务变化使面板不再适用时会关闭并恢复可用焦点。设置完成时检查整数总数，校验错误直接显示在面板内；名称与总数继续在开始读取时传给原有任务接口。
- “帮助”中增加外观偏好：跟随系统 / 浅色 / 深色、40–100% 玻璃浓度（默认 72%）及减少动态效果。偏好以 `xhs-panel-preferences` 保存在扩展页的本机 `localStorage`；不可读写时使用默认值，不影响采集。系统减少动态效果优先生效，减少透明度设置使用实色背景。
- 按钮按下、任务状态变化和 sheet 开合使用已选设计的轻量反馈；只在状态实际改变时播放，不因轮询重复装饰。`popup-view.js` 负责图标、材质偏好、面板和焦点，`popup.js` 继续负责真实任务状态与命令。
- 本地组件沿用固定版本 **daisyUI 5.8.2**，图标使用 **Lucide 0.468.0** 原始 SVG；组件、图标、字体及许可全部随扩展打包。`vendor/daisyui/` 与 `vendor/lucide/` 保存来源和校验，Lucide 图标通过本地 `icons.js` 映射插入，不在运行时请求 CDN，也不引用设计稿文件。
- 图片任务保留独立进度、暂停/继续、已保存张数及齐全笔记数；不能推断为当前正文任务的图片覆盖率。失效列表、原因和分页保留，现有 Native Messaging、读取、访问限制与补图流程不被设计稿的合成数据取代。

验证入口为 `scripts/panel_smoke.py`、`scripts/popup_window_smoke.py` 和隔离集成检查 `scripts/browser_smoke.py`。面板检查覆盖合成状态的布局、sheet、键盘、偏好和进度语义。真实弹窗检查使用 `chrome.action.openPopup()` 测量自动尺寸。测试截图使用合成资料。

## 历史记录：2026-11-24 紧凑面板与并排圆环

以下为采用 iOS 风格之前的实现记录；字号、颜色、尺寸与折叠交互以本页当前实现章节为准。

- 面板固定宽 360px，最大高度 600px；顶栏 56px，内容左右内距 16px。`html` 与 `body` 均显式设置宽度和最小宽度，不使用 `100vw` 限制自身宽度，避免浏览器根据内容自动定尺寸时困在初始窄视口。保留陶土红与 MiSans，正文/按钮 13px、辅助文字 12px、收藏名称 16px。
- UI 组件使用固定版本 **daisyUI 5.8.2**：官方 [Button](https://daisyui.com/components/button/)、[Radial progress](https://daisyui.com/components/radial-progress/)、Badge 和 Alert。按钮的层次、按压与焦点反馈来自组件库，应用只设置颜色、字号、尺寸与布局；保留等宽数字和减少动态效果适配。
- 其余控件同样使用 daisyUI：设置采用 Input、Fieldset、Label，范围确认采用 Checkbox；读取详情、图片详情、失效列表和设置使用保留原生 `details/summary` 的 Collapse；进度、图片与帮助容器使用 Card；失效条目使用 List，顶部及底部使用 Navbar，许可链接使用 Link。底部按钮仍控制独立折叠内容，保留焦点返回和 `aria-expanded`。应用只做紧凑尺寸及主题适配，删除原有输入框外观、复选框颜色、折叠箭头及列表分隔线实现。
- `body` 显式继承主题字体，覆盖 Chrome 扩展页默认的字体声明，确保真实工具栏弹窗与普通页面预览均使用 MiSans。
- 收藏列表与正文保存使用同排 Radial progress，圆环展示数量比例，环下显示完整计数和业务状态。数量达到 100% 不代表列表已确认收齐；未知总数、零分母和断连时显示静态空环与“—”，不展示百分比。进度区使用等宽自动列，第三项布局通过合成指标验证。
- 官方 CSS 与 MIT 许可证原样保存在 `browser-extension/vendor/daisyui/`，`sources.json` 记录源 URL、版本、字节数与 SHA-256。扩展运行时只加载包内文件，无 CDN 请求；不引入远程脚本或新的运行时框架。更新时应核对上游文件及许可证，再更新来源清单并运行面板与真实弹窗验证。
- 补图报告没有所属收藏/正文任务标识，因此图片任务继续独立展示，不能据此推断是当前收藏的图片进度。图片详情保留齐全笔记数、失败原因；已保存张数与完整性分开表达。
- 去除口号、开始前介绍卡和常驻技术范围说明；常用操作采用两列等宽按钮。不可用入口禁用并说明原因。已有正文待处理时先恢复任务，处理结束后再显示更新收藏。
- 顶栏刷新始终可用；访问受限时显示“重新检查”，检查不会自动继续。错误放在主内容顶部，详细原因按需展开。
- 底部固定“读取详情 / 设置 / 帮助”，设置保留名称与核对总数，帮助收纳正文/图片范围及字体许可。失效列表入口与分页保留。
- 验证入口：`scripts/panel_smoke.py` 检查合成状态下的圆环、键盘和固定宽度布局；`scripts/popup_window_smoke.py` 通过 `chrome.action.openPopup()` 检查真实工具栏弹窗首次打开、重开与状态切换的自动尺寸，不为弹窗预设视口。`scripts/browser_smoke.py` 保留隔离 Native Messaging 集成验证。界面截图使用合成数据，不代表真实收藏读取结果。

以下为 2026-11-20 早期设计记录，依据当时的 `browser-extension` 源码与 README；原型数字均为示例，不代表真实收藏覆盖率。

## 1. 插件负责什么

目标：把用户当前打开的收藏列表及笔记正文保存到本机，供 Agent 搜索、追读和引用。

| 用户任务 | 现有能力 | 面板应表达什么 |
| --- | --- | --- |
| 建立本机连接 | Native Messaging 自动启动本机组件；缺失时提示安装 | 常驻连接状态；仅缺失时出现安装说明与重试 |
| 确定读取范围 | 识别页面、收藏/笔记标签、名称与总数 | 当前来源与识别结果；范围不明才显示勾选确认 |
| 开始/更新收藏 | 自动滚动收集链接；同一收藏可续读或更新 | 开始前一个明确主按钮；已有任务时以任务为主体 |
| 了解进度 | discovered、expected_count、body_available、items | 列表收集与正文保存分别报告，未知总数不造百分比 |
| 暂停与恢复 | 后台任务持久化；其他网页也能操作 | 暂停/继续与返回原收藏页；关闭面板仍继续 |
| 核对列表末尾 | 自动终点、等待确认、部分保存 | 明确区分“确认已到末尾”和“先保存已读内容” |
| 补全未完成正文 | 重试；浏览器逐篇打开后台笔记读取 | 失败原因与补全入口；说明会打开后台页及遇验证会暂停 |
| 修正识别结果 | 自定义名称与已核对总数 | 低频选项折叠，保留原值、焦点及输入校验 |
| 使用已保存内容 | CLI / Codex Skill 检索 | 完成后说明可交给 Agent 使用；不虚构插件内搜索功能 |

当前范围：标题、文字正文与原文链接；0.5.0 在独立卡片提供图片获取与进度，OCR、视频仍不处理。不能将“正文已保存”写成“完整归档”。不新增 Cookie 导出、收藏夹私有接口、自动登录或任务删除。

## 2. 信息架构与取舍

1. 顶部：用户选定的 C「文脉」交错纸带标志、产品名称、轻量本机连接状态。标志为透明图形，与陶土红界面配套。
2. 内容：无任务时突出当前收藏与读取按钮；有任务时优先展示任务，不重复放两个等权卡片。
3. 进度：列表“已发现 / 已知总数”与正文“已保存 / 已发现”分开。正文保存率只代表已发现项，列表收齐必须另有证据。
4. 操作：只在当前状态突出适用主操作。错误说明就近出现，技术错误详情折叠；返回收藏页保持可见。
5. 底部：当前版本正文范围提示、名称/总数修正等低频入口。保留“关闭面板继续”和“扫描时保留原标签页”的区别。

宽度从 360px 调整为 400px，最大高度 600px，内容超出时纵向滚动。间距以 4/8/12/16/24px 为基础；状态同时使用文字，不能只靠颜色。

2026-11-20 用户已选定陶土红与 MiSans，实际扩展采用以下规格：

辅助标签和页脚保留 11–12px，顶部产品名称为 15px / 600。成功和警告保留语义色。扩展内置 MiSans 原版 Regular、Semibold WOFF2，不需要安装字体或联网加载；许可说明在“修正名称与总数”内可查看。数字采用等宽数字排版。

## 3. 状态与下一步

| 状态 | 主信息 | 下一步 |
| --- | --- | --- |
| 首次安装 | 本机组件未安装 | 安装说明、安装后重试 |
| 无收藏入口/错误标签 | 请打开收藏 → 笔记 | 切换页面后刷新识别 |
| 待开始 | 已识别名称、总数或未知总数 | 读取当前收藏夹 |
| 范围待确认 | 无法确定当前列表 | 勾选确认后读取 |
| 正在读取 | 列表与正文各自进度 | 暂停；返回收藏页 |
| 已暂停 | 已保存的数据保留 | 继续读取 |
| 等待核对末尾 | 暂时不再加载，未证明收齐 | 继续读取、确认末尾、先保存 |
| 需补全正文 | 展示未完成数量与原因 | 浏览器补全或重试 |
| 浏览器读取中 | 后台页逐篇读取 | 暂停；遇登录/验证停下 |
| 正文已保存 | 正文可检索，列表完整性单独标识 | 回到收藏页、更新 |
| 部分保存 | 已保存正文可用，但列表未收齐 | 明确保留未确认标记 |
| 自定义选项展开 | 名称与核对总数 | 键盘输入；修改后开始下一次读取 |

浏览器补全、继续、完成确认、暂停等沿用现有消息协议。正常读取中不提前把补全作为主操作；有未取得正文、访问限制或停止且未完成时才突出补救。

## 4. 动效

| 触发 | 方案 | 用途 | 减少动态效果时 |
| --- | --- | --- | --- |
| 按钮悬停/按下 | 背景与边框 120ms | 立即反馈可操作性 | 即时更新 |
| 后台进度更新 | 进度填充 transform 220ms ease-out；数字直接更新 | 看清真实增量；不虚构计时 | 即时更新 |
| 任务状态变化 | 内容轻淡入 160ms，仅状态实际变化时 | 保持上下文连续 | 即时切换 |
| 展开低频选项 | 即时展开，箭头 140ms 旋转 | 表明折叠关系，不拖延输入 | 即时更新 |

不滚动数字、不反复呼吸、不持续装饰性转圈。刷新周期沿用 2.5 秒，不重放入场动画。Figma 的状态跳转为演示；其示例数据与定时转换不连接真实任务。实际实现遵循 `prefers-reduced-motion`，键盘焦点与按钮请求不等待动画。

## 5. 验证约束

Figma 需为可编辑文本、自动布局、复用组件与变量，具有主流程及异常状态的可点击连接；不以整张截图充当原型。实际扩展验证覆盖原有消息动作、未知总数、部分保存、浏览器补全、长名称、键盘焦点和减少动态效果。合成测试与真实小红书全量读取验收分开记录。
